- 평소 작업은 개인 위키에 먼저 기록하고, 공개할 만한 것을 골라 이곳에 올립니다.
- 글 하나에는 개념 하나, 또는 문제 해결 하나만 담습니다.

- **Infra & Automation** — 서버 운영, 자동화
- **AI Tools** — AI 도구 활용
- **Troubleshooting** — 문제 해결
